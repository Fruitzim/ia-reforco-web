# 🤖 Laboratório de Aprendizado por Reforço no Navegador

Um projeto interativo para treinar e testar agentes de Inteligência Artificial usando **Reinforcement Learning (Gymnasium e Stable-Baselines3)** direto pelo navegador, com interface construída em **Streamlit**.

## 🚀 Funcionalidades
- Treinamento rápido de agentes de IA usando o algoritmo PPO.
- Teste prático do ambiente clássico do CartPole.
- Visualização de recompensas e métricas de desempenho em tempo real.

## 🛠️ Tecnologias Utilizadas
- Python
- Gymnasium
- Stable-Baselines3
- Streamlit Cloud
